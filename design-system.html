components

dropdown-trigger

An inline button that toggles a paired dropdown-panel. Renders as an inline element to sit naturally inside body text. Pairs with dropdown-panel via the for attribute.

demo

with color: note taker

panel content

without color: note taker

panel content

attributes

  • for required
    ID of the paired dropdown-panel. Works like the HTML label for attribute.
  • bg optional
    Button background when the panel is closed. Accepts any CSS value or custom property.
  • bg-open optional
    Button background when the panel is open. Also used as the focus-visible outline color.
  • body-bg optional
    Sets --color-surface on <html> while open, transitioning the page background color.

example 

<dropdown-trigger
  for="my-panel"
  bg="var(--color-mint)"
  bg-open="var(--color-lime)"
  body-bg="var(--color-mint-soft)"
>label</dropdown-trigger>

<dropdown-panel id="my-panel">
  <!-- slotted content -->
</dropdown-panel>

dropdown-panel

A collapsible content container that animates open and closed using grid-template-rows, avoiding layout shift. Content is accepted via a slot. Managed by dropdown-trigger.

attributes

  • id required
    Referenced by dropdown-trigger via its for attribute.
  • variant="scroll" optional
    Fixed-height scrollable panel. Height controlled by --dropdown-scroll-max-height (default: min(55vh, 28rem)).
  • open optional
    Boolean. Managed automatically — set on load only to pre-open a panel.

css parts

  • ::part(panel) Outer wrapper. Gains margin-top: 0.75rem when open.
  • ::part(content) Animated inner div controlling the open/close transition.

events

  • dropdown:state-changed Bubbles from the panel when it opens or closes.
  • dropdown:close-all Dispatch on document to close all panels. Pass detail.exceptId to keep one open.

accessible-select

A shadow-DOM combobox implementing the WAI-ARIA listbox pattern as a native <select> replacement. Options aren’t known until Contentful data loads, so they’re set programmatically with setOptions() rather than as markup. Used by the blog panel’s year filter.

demo

attributes

  • disabled optional
    Boolean. Also readable/settable as the .disabled property.
  • placeholder optional
    Label shown before the reader has picked an option. Once they commit a value, the picked option’s label replaces it — even if that value is an empty string (e.g. an “all” option).

properties & methods

  • value Get or set the current selection by its value.
  • setOptions(options) Replaces the option list. Takes an array of { value, label }. If the current value isn’t in the new list, it falls back to the first option.

css parts

  • ::part(trigger) The clickable combobox button.
  • ::part(listbox) The popover list of options.

events

  • change Fires when the reader picks an option. detail: { value }.

example 

<accessible-select id="year-filter" placeholder="all years"></accessible-select>

<script>
  document.getElementById('year-filter').setOptions([
    { value: '', label: 'all years' },
    { value: '2026', label: '2026' },
  ])
</script>

image-element

A shadow-DOM wrapper around a native <img>, used for Contentful-sourced images across the blog, code, and music panels. Exists so image rendering has one owned place to add shared behavior later, rather than every panel writing its own <img> markup.

demo

attributes

  • src optional
    Image URL. Omitting it removes the internal src entirely rather than rendering a broken-image icon.
  • alt optional
    Defaults to an empty string, not a missing attribute — treat every image as needing real alt text.
  • width / height optional
    Applied as inline CSS on the internal <img>, so any CSS length works (e.g. 12rem), not just a bare pixel number.
  • loading / decoding optional
    Passed straight through to the internal <img> (e.g. loading="lazy").

css parts

  • ::part(img) The internal <img> element.

example 

<image-element
  src="/assets/share-2.jpg"
  alt="Dan Hemerlein"
  width="12rem"
  loading="lazy"
></image-element>

video-element

A shadow-DOM looping background video, used for the site’s 3D UFO and Saturn clips. On Safari, which decodes VP9 WebM but ignores its alpha track, it composites a two-column color+alpha-mask .webm onto a <canvas> frame by frame instead; every other browser plays the .webm directly, since it supports WebM alpha natively.

demo

attributes

  • src required
    Path to the color+alpha .webm. On Safari the component swaps .webm for _split.webm and expects that file to exist alongside it.
  • description optional
    Becomes a visually-hidden caption for screen readers. The video itself is aria-hidden, so this is the only description assistive tech will announce.
  • show-controls optional
    Boolean. Reveals a play/pause button overlay.

properties & methods

  • setPlaying(playing) Plays or pauses this instance. Clicking any video-element’s own play/pause button calls this on every video-element on the page, so all background clips play or pause together.

example 

<video-element
  src="/assets/ufo.webm"
  description="A looping animation of a 3D UFO."
  show-controls
></video-element>

theme-toggle

The light/dark switch shown in the top-right corner of every page (see this page’s own corner). Reads and writes the data-theme attribute on <html> and persists the choice to localStorage. Dark mode is opt-in only: a first-time visitor always sees light mode, regardless of their OS prefers-color-scheme — theme-init.js applies the stored choice (or defaults to light) before first paint, so there’s no flash of the wrong theme.

demo

See the toggle in this page’s own top-right corner. theme-toggle is styled position: fixed globally (in css/theme-toggle.css), so a second instance placed inline here would render on top of that corner instance instead of inside this box.

attributes

None. Add it anywhere in the document; every instance stays in sync since they all read and write the same data-theme attribute — though in practice, only one should ever be on the page at a time, given the fixed positioning above.

events

  • theme:changed Dispatched on document when the mode changes. detail: { theme: 'light' | 'dark' }.

example 

<theme-toggle></theme-toggle>

blog-panel

Renders the Blog panel’s full list-to-detail view: a year-filterable, infinite-scroll list of posts (via accessible-select and an IntersectionObserver), and an article detail view rendered with the site’s local rich text renderer. A zero-configuration singleton — it builds its own markup and fetches its own content as soon as it’s connected to the page.

attributes

None. Slot it inside a dropdown-panel and it handles the rest.

events

  • dropdown:state-changed Listened for on document, so the panel can hide the site’s introductory copy behind it while open.

example 

<dropdown-panel id="blog" variant="scroll">
  <blog-panel></blog-panel>
</dropdown-panel>

code-panel

Renders the Writes Code panel: a list of code projects that opens into a detail view with a hero image, a timeline, and the project’s rich text body. Fetches its full project list in one request — no pagination, unlike blog-panel.

attributes

None. Slot it inside a dropdown-panel and it handles the rest.

example 

<dropdown-panel id="writes-code" variant="scroll">
  <code-panel></code-panel>
</dropdown-panel>

music-panel

Renders the Makes Music panel’s list view. Fetches every music project in one request via window.fetchAllMusicProjects() — the simplest of the four panels, with no filtering, pagination, or detail view of its own.

attributes

None. Slot it inside a dropdown-panel and it handles the rest.

example 

<dropdown-panel id="makes-music" variant="scroll">
  <music-panel></music-panel>
</dropdown-panel>

moodboard-panel

Renders the Collects Moods panel’s image grid, paging through entries with an IntersectionObserver as the reader scrolls, the same pattern blog-panel uses for its list. Also watches a media query to adjust its grid on resize.

attributes

None. Slot it inside a dropdown-panel and it handles the rest.

events

  • dropdown:state-changed Listened for on document, so the panel can hide the site’s introductory copy behind it while open.

example 

<dropdown-panel id="collects-moods" variant="scroll">
  <moodboard-panel></moodboard-panel>
</dropdown-panel>
