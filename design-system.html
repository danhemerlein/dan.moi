components

dropdown-trigger

An inline button that toggles a paired dropdown-panel. Renders as an inline element to sit naturally inside body text. Pairs with dropdown-panel via the for attribute.

demo

with color: note taker

panel content

without color: note taker

panel content

attributes

  • for required
    ID of the paired dropdown-panel. Works like the HTML label for attribute.
  • bg optional
    Button background when the panel is closed. Accepts any CSS value or custom property.
  • bg-open optional
    Button background when the panel is open. Also used as the focus-visible outline color.
  • body-bg optional
    Sets --color-surface on <html> while open, transitioning the page background color.

example

<dropdown-trigger
  for="my-panel"
  bg="var(--color-mint)"
  bg-open="var(--color-lime)"
  body-bg="var(--color-spring)"
>label</dropdown-trigger>

<dropdown-panel id="my-panel">
  <!-- slotted content -->
</dropdown-panel>

dropdown-panel

A collapsible content container that animates open and closed using grid-template-rows, avoiding layout shift. Content is accepted via a slot. Managed by dropdown-trigger.

attributes

  • id required
    Referenced by dropdown-trigger via its for attribute.
  • variant="scroll" optional
    Fixed-height scrollable panel. Height controlled by --dropdown-scroll-max-height (default: min(55vh, 28rem)).
  • open optional
    Boolean. Managed automatically — set on load only to pre-open a panel.

css parts

  • ::part(panel) Outer wrapper. Gains margin-top: 0.75rem when open.
  • ::part(content) Animated inner div controlling the open/close transition.

events

  • dropdown:state-changed Bubbles from the panel when it opens or closes.
  • dropdown:close-all Dispatch on document to close all panels. Pass detail.exceptId to keep one open.
